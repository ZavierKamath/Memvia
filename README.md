# Memvia

Memvia is a hand-coded project by Zavier Kamath

## Project Description

Memvia uses AI to:
- Provide answers to questions on job applications
- Create resumes with strict formatting

It does this by using the store of memories at its disposal, which are curated by the user.

## Tech Stack
- Python backend (FastAPI, Pydantic AI, OpenRouter, Sqlite)
- React frontend (TypeScript, Tailwind, Vite)
